Email kit

Two ready-made blocks for Gmail. Select everything inside a white box, copy it, and paste it where the steps say.

1. Signature

  1. Select everything inside the white box below and copy it (Cmd + C).
  2. In Gmail open Settings (gear) → See all settings → General → Signature → Create new, name it “Sandra's Bake House”.
  3. Paste (Cmd + V) into the signature box.
  4. Under Signature defaults choose it for new emails and replies, then Save Changes at the bottom of the page.

2. Banner for the first email to a café

  1. Click once on the banner below so it is selected, then copy it (Cmd + C).
  2. Paste (Cmd + V) into the body of the email, usually right after the greeting.
  3. The banner is already a link: anyone who clicks it opens the website.

If the banner doesn't paste as a picture, use Gmail's Insert photo → Web address (URL) with
https://sandras-bake-house.vercel.app/email/banner.jpg, then select it and add the link with Cmd + K.
